### 暴露的核心失衡
1. **高阶密度偏低**：由于独立基地采用 `RoamingDensityScale = 0.85 / 0.80` 控制大图帧率，若直接沿用原版比例，中阶 `Strong`（`~103/千格`）仅剩原版一半，分离模式 `T3`（`86~93/千格`）亦明显低于原版（`133.3/千格`）。
2. **一刀切折算不合理**：旧版 M4 对所有 T3 统一使用 `9:1`（T1→T3）/`3:1`（T2→T3）折算，忽视了不同僵尸对后期主力**狙击手（单发 `100` 伤害、无溅射）**的 BTK（击杀所需枪数）与输出威胁差异。

## 2. 后期主力（狙击手）BTK 与僵尸输出威胁模型

### 2.1 野图推进场景（流动狙击手群，无城墙/无电塔 AOE）

| 僵尸类型 | 狙击手 BTK | 输出模式与威胁特征 | 等效 BTK 威胁权重 |
|---|---:|---|---:|
| **Weak (T1)** | `1` 枪（过量伤害浪费） | 慢速近战，8 格射程外即被点死，对成型狙击群几乎无输出 | **`1.0`** |
| **Med / Strong (T2)** | `1~2` 枪（均约 `1.3~1.6` 枪） | 跑尸/高移速/中高血量，成群可消耗前排或迫使走 A | **`1.6`**（输入预算） |
| **Chubby (胖子 T3)** | **`5~6` 枪** | 慢速纯肉盾，核心作用是吸收大量狙击手开火轮次 | **`5.0`** |
| **Venom (毒液 T3)** | **`2` 枪** | 远程 AOE 酸液吐息，可隔着肉盾融化扎堆狙击手 | **`3.0`** |
| **Harpy (女妖 T3)** | **`2` 枪** | 极高移速 + 翻墙 + 高频近战，容错率最低 | **`3.0`** |

**核心推导**：
- **若统一用 `4:1` 或 `9:1` 换算女妖/毒液**：女妖/毒液仅需 2 枪，按 `4:1` 甚至 `9:1` 换算会直接砍半狙击手总开火次数，导致 `SwarmHunter`/`Caustic` 图比原版更好推；
- **若统一用低比例换算胖子**：胖子需 5~6 枪，换多之后极易拖慢推进节奏变成刮痧。
- 因此采用 **BTK 权重预算池**：抽调外圈 `60% T1`（每只 `+1.0`）与 `45% T2`（每只 `+1.6`）进入预算池，生成 `Chubby` 扣除 `5.0`、生成 `Venom/Harpy` 扣除 `3.0`（在 `num49 >= 3` 且预算充足时按 `1/3` 概率升级双怪格并双倍扣费）。

### 2.2 分圈升格与中低阶回填（兼顾高阶密度与总量）

1. **近圈（`d_min < minMed`）**：`100%` 保留原版动态噪声安全圈与刷怪结果。
2. **中圈（`minMed <= d_min < effOuterStart`）**：抽取 `40%` `Weak(T1)` 按 **`2.5 : 1`** 升格为 `Strong`（70%）/`Medium`（30%），补回中圈扩图阻力。
3. **外圈（`d_min >= effOuterStart`，聚集模式取 `minPowerful`，分离模式内收 `10` 格对齐外圈面积）**：执行上述 **BTK 权重预算升格**，并在 `d_min >= 85` 按每 `28` 个 T3 凝聚 `1` 只外围巨人（受 `maxCondensedGiants` 上限约束）。
4. **中低阶回填补足（`d_min >= minWeak`）**：升格压缩会置空部分消耗格，导致全图总实体数下降；因此在完成升格后，于 `d_min >= minWeak` 的合格空噪声格中回填 `Weak2`（50%）、`Runners1`（25%）、`Medium1`（25%），将总僵尸数恢复至 `min(25,000, round(升格前总数 × 1.10))`，在控制 30Hz 锁步算力的同时保持“尸海掩护精英”的完整混编体感与 AOE 兵种价值。
